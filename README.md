# Рассказчик у камина: озвучка на своём компьютере

Озвучка хоррор-историй клонированным голосом (ESpeech + RUAccent), всё работает локально на видеокарте NVIDIA.

## Скачать

**[Rasskazchik-Setup.exe](https://github.com/vadimdavyd51-dot/Sintez/releases/latest/download/Rasskazchik-Setup.exe)**

1. Запусти скачанный файл. Windows может предупредить «неизвестный издатель»: нажми «Подробнее» → «Выполнить в любом случае».
2. Дождись окончания: установщик сам поставит Python, PyTorch и скачает модели (15-30 минут, нужен интернет, около 15 ГБ места).
3. Открой «Рассказчик» ярлыком на рабочем столе: в браузере откроется страница, куда вставляется сценарий.

Подробная инструкция по работе: [app/README.txt](app/README.txt).

## Для разработки

- `app/`: сама программа (`engine.py` движок озвучки, `app.py` локальная страница, `voices/` и `voices.json` образцы голоса).
- `installer/rasskazchik.iss`: скрипт установщика (Inno Setup).
- `.github/workflows/build-installer.yml`: при каждом изменении в `main` собирает `Rasskazchik-Setup.exe` и обновляет релиз `latest`.
